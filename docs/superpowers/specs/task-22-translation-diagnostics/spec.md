# Задача 22 — точные причины ошибок перевода

## Цель

Показывать, какое условие проверки перевода не прошло, не записывая текст материалов и перевода в журнал.

## Требования

- Разделить общий `schema_translation` на фиксированные категории: неверная структура объекта, неверный/неожиданный/повторный ID, отсутствующий перевод, неверный тип/пустое название, неверный тип/слишком длинный текст, пустой перевод для непустого оригинала.
- Сохранить отдельную проверку языка `schema_language_translation`.
- Не включать в диагностическое событие данные материалов, значения перевода или исключения с ними.
- Не менять поведение очереди: невалидный ответ отклоняется, очередь остаётся без изменений.

## Приёмка

- Для каждой ветки проверки есть тест с точным кодом ошибки.
- В stderr присутствует только allowlist-код; контрольные строки из материала и перевода отсутствуют.
