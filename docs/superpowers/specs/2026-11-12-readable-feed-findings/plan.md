# План реализации — удобочитаемые «Находки» и лента

**Цель:** реализовать утверждённую задачу 12 из `spec.md` одним коммитом.

**Подход:** использовать текущие `feed_findings` и `feed_materials`, не менять контракты API и порядок находок. Менять только структуру/стили Mini App и SQL-условие снимка исходной ленты, чтобы исключённые ожидающие перевода материалы не попадали в total и курсор. Тесты пишет отдельный агент; полный набор запускает другой агент.

## Шаги

1. **RED — UI-тесты.** Отдельный тестовый агент расширяет `tests/miniapp_feed_translation_test.js` проверками стартовой вкладки, структуры раскрываемых фильтров и деталей карточек; тесты не запускает.
2. **RED — тест API/выборки.** Тестовый агент добавляет в `tests/test_feed.py` случай с материалами `pending` и `ready`; ожидает, что total, выдача и курсор учитывают только видимые материалы. Не меняет production-код.
3. **Подтвердить RED.** Отдельный агент запускает указанные тесты на текущей реализации и фиксирует ожидаемые падения.
4. **GREEN — интерфейс находок.** В `web/miniapp.html` сделать «Находки» стартовой вкладкой, поместить вторичные фильтры в `<details>`, показать активные условия компактно, оформить карточки находок через семантическое раскрытие подробностей и источников.
5. **GREEN — исходная лента.** Уплотнить типографику и интервалы карточек/заголовков без потери читаемости. В `db/__init__.py` исключить `pending` из создания снимка `feed_materials`, чтобы согласованно изменить выдачу, счётчик и пагинацию.
6. **Проверка интерфейса.** Запустить Node UI-тест; проверить HTML/JS-синтаксис и `git diff --check`.
7. **Полный набор.** Другой независимый агент запускает весь набор командой из README на изолированной PostgreSQL; 3 Docker smoke-теста допустимо считать пропущенными только если Docker недоступен.
8. **Финальная проверка и коммит.** Сверить изменения с SPEC, обновить README, Kanban и progress, проверить `git diff --check`, затем создать один коммит `feat(12): improve feed and findings readability`.

## Review focus

- Фильтры вторичного уровня должны сохранять текущие значения, счетчики, доступность с клавиатуры и реакцию на изменения.
- Пагинация исходной ленты должна использовать тот же набор данных, что total; `pending` исключён до формирования snapshot.
- Выборка находок сохраняет текущую сортировку и состав связанных источников.
- Стартовая вкладка не должна обходить создание Mini App-сессии.
- На мобильной ширине элементы управления не создают горизонтальную прокрутку.
