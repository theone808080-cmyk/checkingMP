# Задача 20 — безопасные метаданные ответа OpenRouter

## Цель

Упростить диагностику некорректного ответа модели без записи в журналы текстов новостей, ответов модели или секретов.

## Требования

- При ошибках этапа `content` журнал включает допустимое значение `finish_reason`, длину текста ответа и размер отправленного запроса в байтах.
- Неизвестный или некорректный `finish_reason` выводится как `unknown`.
- Текст входной пачки и ответ модели в журнал не включаются.
- При ошибке содержимого очередь остаётся без подтверждения; поведение запросов к OpenRouter не меняется.

## Приёмка

- Тесты покрывают метаданные, неизвестные значения и отсутствие утечки содержимого/секретов.
- Целевые тесты проходят; `git diff --check` чистый.
