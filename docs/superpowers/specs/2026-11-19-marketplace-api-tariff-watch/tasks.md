## Интерфейсы для тестирования

- Клиенты должны принимать подменяемый transport, чтобы тесты не обращались к реальным API.
- API-ответы проверяются на реальных полях фикстур; тестовые ключи — только фиктивные строки.
- Функция сравнения принимает нормализованные записи текущего и последнего успешного снимка и возвращает стабильные дельты независимо от порядка ответа API.
- Сохранение снапшота и создание event/material/impact проверяется на отдельной PostgreSQL БД, не на production.
