# Задача 21 — находки с неизвестной площадкой

## Цель

Не останавливать всю обработку пачки из-за площадки, которую модель указала в одном сигнале, и сохранить такой сигнал для ручной проверки.

## Поведение

- Если название площадки — строка, но оно не распознаётся, сохранить сигнал с площадкой `Не определено` и проверкой `needs_check`.
- Типы площадки, отличные от строки, и пустые значения по-прежнему отклонять.
- Остальные сигналы и материалы пачки обрабатывать по текущим правилам.
- Допустить служебную площадку `Не определено` при импорте события; не менять другие алиасы и категории.
- Не записывать исходное неизвестное значение площадки в диагностический журнал.

## Приёмка

- Сигнал с неизвестной строковой площадкой проходит в черновик `Не определено` с `needs_check`.
- Остальные сигналы пачки сохраняются; некорректные типы/пустые значения продолжают отклоняться.
- Точечные и полные тесты проходят; проверка очереди подтверждает, что материалы обработаны без потери.
