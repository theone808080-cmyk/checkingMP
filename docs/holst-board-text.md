# Текст для доски Holst

Подготовлена гибридная архитектура: Railway предназначен для сбора публичных материалов, хранения в частной PostgreSQL и защищённой веб-страницы. Collector запускается по расписанию `0 6,18 * * *` и завершает работу. Локальный LM Studio выполняет обработку только по ручному запуску; сигналы проверяет человек.

Развёртывание не выполнено. Ручной `process` может обращаться к защищённому API по HTTPS, если локально заданы адрес и токен; без них он работает с локальной PostgreSQL. Сквозная работа в Railway ещё не проверена. Доступность cron после пробного периода и настройки расходов нужно проверить в выбранном тарифе до запуска.
